Weekly (lab) assignments do not allow the use of **any** AI tools, including AI code completion or chat assistants built into or added to your editor (e.g. GitHub Copilot, Codeium, Cody, Tabnine). Before starting a lab, make sure these are turned off:

1. Open the **Extensions** view (`Ctrl+Shift+X` / `Cmd+Shift+X`).
2. Find any AI coding assistant extensions you have installed and click the gear icon next to each, then choose **Disable**. If you're connected to your VM over Remote-SSH, extensions run per-remote, so make sure to disable them for the remote connection you use for CS 341 (choose **Disable (Workspace)** if that's an option), not just on your local machine.
3. If you have GitHub Copilot installed, you can also click its icon in the bottom status bar and select **Disable Completions**, or add `"github.copilot.enable": false` to your `settings.json`.

Double check that no inline "ghost text" suggestions or chat panel appear while you work on a lab. If you're unsure whether a tool counts as AI assistance, ask on EdStem before using it.
