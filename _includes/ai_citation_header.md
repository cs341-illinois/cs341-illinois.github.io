## AI Citation Policy

For this assignment all use of AI is expected to be documented in the following format 

```c
/* 
@cite [CLASSIFICATION]
@tool [e.g., ChatGPT-4o, GitHub Copilot]
@desc [Briefly explain what the AI did and what you asked it to do]
*/
 ```

`[CLASSIFICATION]`

- `[AI-GEN]`: Code was generated by AI and used with minimal changes.
- `[AI-PARTIAL]`: AI provided a skeleton or logic snippet, but you heavily modified it.
- `[AI-BRAINSTORM]`: No code was copied; the AI helped explain a concept or debug a logic flow.

Remember, your citations must be added before any Auto Grader run. If you have any questions please make a 
post on EdStem.
